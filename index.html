Limited palette with CSS custom properties

The colors in this page, from darkest to lightest, are all variations of the same base color. CSS "custom properties" (variables) make it easy to adjust them.

There will be no black or white, which can be jarring—only different combinations of foreground and background to create visual coherence.

Accent colors

Highlight colors, such as hyperlinks, can be a color from an opposite (or split-opposite) part of the spectrum.

Reversing foreground and background colors

To keep the number of variations down, the heading color above is the same as the background color of the body.
